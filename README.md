Pasar Malam: Cari Perbedaannya — a spot-the-difference game in three procedural rounds, built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

Three rounds, eight differences each, all scenes drawn procedurally on canvas — no external assets, no network requests. Includes a HUD, hints, sound, and four screenshots.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
